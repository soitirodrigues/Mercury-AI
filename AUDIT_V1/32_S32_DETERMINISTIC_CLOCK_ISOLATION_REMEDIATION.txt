BASELINE (S32-C)
----------------
- Test: S32-C parallel clock isolation
- Finding: DeterministicClock._current_time is SHARED class/global state - NOT thread-local
- Issue: Concurrent threads share the same clock state, causing potential contamination
- Original test (s32_c_parallel_clock_isolation.py): 3/4 workers observed worker D's timestamp under Barrier
- Constraint: Cannot resolve simply by serializing with max_workers = 1 (prohibited by spec)
- Result: R2 = FAIL

DESIGN CHOSEN
-------------
- Option A selected: Thread-local storage via threading.local()
- Rationale: Each thread gets its own _current_time, preventing cross-thread contamination
- Preserved interfaces: snapshot(), restore(), set_time(), utcnow() maintained with compatible behavior
- Minimal patch: Only modified DeterministicClock class, no strategy/signals/weights/thresholds/universe changes
