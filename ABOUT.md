# Sobre a Mercury AI V1.0

A Mercury AI é uma plataforma de decisão institucional baseada em evidências, projetada para alta explicabilidade, rastreabilidade e determinismo para operações assistidas.

**Versão:** 1.0
**Status:** Golden Build
**Arquitetura:** Modular com Pipeline Institucional de ponta a ponta.
**Segurança:** Modo Operacional READ_ONLY ativado.
**Auditoria:** Sistema completo de auditoria estatística, histórico e monitoramento.

Plataforma desenvolvida para uso institucional exclusivo.
