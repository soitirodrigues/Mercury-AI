# Manual do Operador - Mercury AI V1

Bem-vindo ao Mercury AI. Este manual guia o operador no uso do Terminal Operacional.

## Acesso
Execute `streamlit run app/launcher.py`.

## Painéis Principais
1. **Dashboard Institucional:** Visão geral de viés, confiança e regimes de mercado.
2. **Scanner Institucional:** Monitoramento em tempo real de ativos.
3. **Centro de Operações:** Execução e controle de modo (Demo/Real).
4. **Histórico e Performance:** Trading Journal e estatísticas de sucesso.
5. **Painel de Observabilidade:** Monitoramento de saúde do sistema (CPU/RAM).

## Modo de Operação
- **Demo:** Execução bloqueada para execução real, usado para testes.
- **Real:** Execução habilitada (requer configuração de credenciais).

## Exportação de Dados
Utilize o botão "Exportar" no Dashboard para gerar relatórios em CSV, JSON, Excel e ZIP.
